Isle trust setup

Probing whether this device trusts the isle…

This isle serves its apps over HTTPS using its own certificate authority. Trusting that CA once makes every *.isle app load cleanly on this device.

Download the isle root certificate — verify its fingerprint against the one shown by the isle operator (isle trust cert) before trusting.

How to trust it

  • Linux + Chrome/Chromium: run isle trust install (isle CLI installed), or import via Settings → Privacy and security → Security → Manage certificates → Authorities.
  • Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.
  • iPhone/iPad: download above, then Settings → Profile Downloaded → Install; then Settings → General → About → Certificate Trust Settings → enable full trust.
  • Android: download above, then Settings → Security → More/Encryption → Install a certificate → CA certificate.
